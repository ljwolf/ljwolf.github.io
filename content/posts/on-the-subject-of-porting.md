<p>On this, the first few minutes of Guido&rsquo;s <a href="https://www.youtube.com/watch?v=G-uKNd5TSBw" target="_blank">PyCon Keynote </a>really hit home.</p>

<blockquote>
<p>Yes you should all be using Python 3, and I know that you all want to, but I know it&rsquo;s difficult. You all have large amounts of Python 2 code in production that you&rsquo;ve ported to Python 2.7.9 &hellip; but the step to Python 3 from there is still phenomenal.</p>

<p>You can&rsquo;t just fix a few style nets and remove a few L&rsquo;s from long integers. You have to actually understand your code. [&hellip;] I know how hard it is, because you don&rsquo;t get the satisfaction of &ldquo;I launched a new feature.&rdquo; <em>No</em>. I rewrote the same app in Python 3. I ported it to a new version of Python.</p>

<p>Does it do the same thing? Yes. Does it do exactly the same thing? hopefully. Is it an exciting launch? <em>No</em>. But you have to do the work, because then the next feature you launch will go better. But, if something holds you up, there are lots of things that still suck in the ecoystem.</p>
</blockquote>

<p>If you&rsquo;re out there porting some code, I hope you listen to the first half of Guido&rsquo;s talk.</p>
